# Rust-encryption apps. 


Mostly Rust encryption apps, there is a little bit of assembly and zig coded encryption apps too. Tiny apps so even free ai can audit/update/customize the apps. As such, this is for educational purposes only and for fun. If you are interested in having ai make encryption apps for you, you need to tell ai the specific threat model you are trying to counter. And make sure to tell ai to code it in Rust :)
